🚗 Ola Ride Analytics --- Excel Dashboard

An end-to-end Ola Ride Analytics project built in Microsoft Excel to
analyze ride bookings, revenue, cancellations, customer behavior,
vehicle performance, and operational trends through an interactive
dashboard.

📌 Project Overview

This project transforms raw ride-hailing data into meaningful business
insights using Excel-based data analysis and visualization.

The dashboard is designed to answer questions such as:

How many rides were completed, cancelled, or lost?

What is the total revenue generated?

Which vehicle types perform best?

Which locations/cities generate the most rides and revenue?

What are the major cancellation reasons?

How do bookings and revenue change over time?

What is the customer and driver rating performance?

Which operational areas need improvement?

🎯 Objectives

Analyze overall ride-booking performance.

Identify revenue and booking trends.

Understand ride cancellations and their major reasons.

Compare vehicle-category performance.

Analyze customer and driver ratings.

Build an interactive and management-friendly Excel dashboard.

Convert raw operational data into actionable business insights.

📁 Workbook Structure

Sheet                 Purpose

Raw_Data            Original ride-hailing dataset used for analysis
Table               Structured data/table used for calculations and analysis
kpi                 KPI calculations and summary metrics
calculated matrix   Supporting calculations and analytical metrics
Chart               Charts and visualizations used in the dashboard
Dashboard           Final interactive dashboard

The separate cleaned-data sheet was intentionally removed from the
final portfolio version because it was redundant; the analysis uses
the required structured data and calculation layers.

🔍 Key Analytical Areas

Ride Performance

Analysis of booking volume, completed rides, and unsuccessful/cancelled

Revenue Analysis

Evaluation of revenue generation across ride categories and operational

Cancellation Analysis

Vehicle Analysis

Rating Analysis

Trend Analysis
